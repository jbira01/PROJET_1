## 📖 Overview

**PROJET_1** is a responsive front-end web application for a Car Rental platform, developed using **HTML5, CSS3, and JavaScript**.

This project represents the foundational version of the system before backend integration.
It focuses on structured UI design, responsive layouts, and user interaction principles.

---

## ✨ Key Features

* 🏠 Landing page with service presentation
* 🚘 Vehicle listing interface
* 📅 Reservation form (UI prototype)
* 🔐 Login & Registration pages
* 📩 Contact form
* 📱 Fully responsive design

## 🚀 Installation & Usage

Clone the repository:

```bash
git clone https://github.com/jbira01/PROJET_1.git
```

Open the project folder and launch:

```
index.html
```

No server configuration is required since this is a static web application.
